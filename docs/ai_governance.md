# AI Governance, Model Registry & Reproducibility

## 1. Overview
ProductIQ AI enforces strict enterprise AI governance across local model runtimes, prompt versioning, and deterministic audit trails. Every analysis output is stamped with immutable metadata enabling 100% reproduction and compliance verification.

---

## 2. Governance Metadata Schema
Every analysis artifact generated by the platform persists the following cryptographic and versioning fields:

- `analysis_id`: Unique deterministic UUID.
- `model_name`: Registered model identifier (e.g., `llama3.2:3b`).
- `model_version`: Exact release version checkpoint (e.g., `1.0`).
- `prompt_version`: Versioned extraction prompt identifier (e.g., `prompt_extract_v10`).
- `pipeline_version`: Deterministic pipeline version (`2.5.0`).
- `source_hashes`: SHA-256 digests of all ingested source documents.
- `timestamp`: UTC timestamp of execution.

## 4. Prompt Template Versioning

- **Extraction Template v1.0** (`prompt_extract_v10`): Strictly mandates JSON outputs and penalizes invented attributes not present in the input text.
- **Enrichment Template v1.0** (`prompt_enrich_v10`): Generates taxonomy categories and B2B synonym terms grounded in verified product names.
- **Conflict Arbitration Template v1.0** (`prompt_conflict_v10`): Classifies discrepancies and executes unit conversion arbitration.
