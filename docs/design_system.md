# ProductIQ AI Design System Specification

## 1. Aesthetic Direction: Industrial Control Center
The user interface is designed specifically for technical operations, catalog engineers, and procurement specialists. It prioritizes information density, crisp typography, and unambiguous status signaling over decorative gradients and animations.

---

## 2. Color System

- Primary Background: `#0F172A` (Slate 900)
- Secondary Surface: `#1E293B` (Slate 800)
- Tertiary / Dividers: `#334155` (Slate 700)
- Technical Primary Accent: `#2563EB` (Engineered Blue)
- Success / Verified: `#10B981` (Emerald Green)
- Warning / Needs Review: `#F59E0B` (Amber)
- Danger / Critical Conflict: `#EF4444` (Rose/Red)
- Info / Telemetry: `#06B6D4` (Cyan)

---

## 3. Typography & Numerical Layouts

- Body & Headers: `Inter`, system sans-serif.
- Technical Values, Units, Part Numbers & Telemetry: `JetBrains Mono`, `Consolas`, monospace.
- Corner Radii: 4px (small elements), 6px (buttons/inputs), 8px (panels).
